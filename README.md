# YouTube Clone
Тестовое задание. Развертывание одной командой.

# Что именно мы будем делать (Scope MVP)
1. Аутентификация (JWT): Регистрация, логин. Роли (user, admin).
2. Видео (Ядро):
3. Загрузка файла (через API, сохранение в MinIO или локально на диск).
4. Список видео (Главная страница).
5. Просмотр конкретного видео (HTML5 плеер, раздача файла с поддержкой Range-запросов для перемотки).
6. Взаимодействие: Лайки и Комментарии (простые CRUD-операции).
7. Приватность: У видео есть флаг is_private. Если он включен, видео видит только автор.

Упрощение: Никаких Celery и ffmpeg (генерацию превью и транскодинг). Сделаем простую заглушку для превью (картинка по умолчанию) или сгенерируем простую обложку на лету. Это сэкономит кучу времени и нервов.


## Инфраструктура:
- docker-compose.yml (FastAPI + PostgreSQL).
- deploy.sh для одной команды.
- README.md и docs/architecture.md (схема БД).
- Пара простых тестов (pytest) на регистрацию и загрузку.

## Что мы выкидываем (чтобы успеть):
- Поиск (или делаем самый примитивный через LIKE).
- Модерацию и жалобы (можно просто добавить поле is_hidden в БД и кнопку для админа, но без сложной логики).
- Плейлисты и подписки (можно добавить таблицы в БД для галочки, но UI не делать).
- Сложный фронтенд (делаем один index.html с минимальным JS и CSS, похожим на YouTube).
